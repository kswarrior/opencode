How to join
  1. Open Minecraft Bedrock Edition (Windows, Android, iOS, Xbox, PlayStation).
  2. Go to Play → Servers → Add Server.
  3. Server address Mayanshanboss.aternos.me, port 63046.
  4. Start the server from the Aternos panel, then join.

About

This is a lightweight stats monitor for the Mayanshanboss Bedrock server (Mayanshanboss.aternos.me:63046). The backend pings the server over the RakNet UDP protocol every minute, keeps a rolling 24-hour history and serves the stats you see here. It is hosted on Render.com.

Aternos servers sleep when nobody is online, so “offline” usually just means the server is not started. History resets when the service redeploys.
