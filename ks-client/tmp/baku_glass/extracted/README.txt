TRANSPARENT GLASS UI V3 — BY BAKU

FIXES:
- New transparent HUD hotbar textures: hotbar_0 ... hotbar_8, caps and selected slot.
- Inventory and crafting windows now use much lower opacity dark neutral panels.
- Cleaner, lighter transparent recipe grid/item slot appearance.
- Removed extra dark background patches.
- Selection indicator intentionally stays visible for gameplay.
- Creator credit: Baku.

INSTALL:
Deactivate previous UI packs, import this V3 .mcpack, activate it at top of
Global Resources and restart Minecraft. Set UI Profile to Classic if needed.
The HUD hotbar appearance may differ or be unsupported in newer Ore UI screens.
This pack has been validated structurally, but not tested inside Minecraft.
