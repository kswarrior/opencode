# Lifestead - Basic Plan

## Goal

Build and release the Lifestead plugin together with its resource pack.

## Deliverables

- `release/plugin/` - compiled plugin artifact(s)
- `release/resource-pack/` - packaged resource pack

## Milestones

1. Define plugin features and behavior.
2. Implement plugin source and configuration.
3. Create and test the resource pack.
4. Build both artifacts into the `release/` folders.
5. Verify installation on a test server.
6. Tag and publish the release.
