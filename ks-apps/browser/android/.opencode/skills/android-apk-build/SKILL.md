# Build the KS Portal APK

Single-module, dependency-free app (`app/src/main`, package `com.ks.android.portal`, minSdk 21, targetSdk 35). There is no Gradle; the APK is produced with the SDK build-tools directly. Run every command from the project root, `ks-apps/browser/android` (the folder containing `app/`).

## Full pipeline (verified)

```bash
SDK="${ANDROID_HOME:-$ANDROID_SDK_ROOT}"
BT="$SDK/build-tools/35.0.1"          # any installed build-tools works
PLATFORM="$SDK/platforms/android-35"  # matches targetSdkVersion 35
SRC="app/src/main"
OUT="build"

rm -rf "$OUT/flat" "$OUT/classes" "$OUT/dex" "$OUT/gen"
mkdir -p "$OUT/flat" "$OUT/classes" "$OUT/dex" "$OUT/gen"

# 1. Compile resources
"$BT/aapt2" compile --dir "$SRC/res" -o "$OUT/flat/res.zip"

# 2. Link resources + manifest + assets, generate R.java
"$BT/aapt2" link -o "$OUT/base.apk" \
  -I "$PLATFORM/android.jar" \
  --manifest "$SRC/AndroidManifest.xml" \
  -A "$SRC/assets" \
  --java "$OUT/gen" \
  "$OUT/flat/res.zip"

# 3. Compile Java (project + generated R.java)
javac -source 8 -target 8 -Xlint:-options \
  -classpath "$PLATFORM/android.jar" \
  -d "$OUT/classes" \
  $(find "$SRC/java" "$OUT/gen" -name '*.java')

# 4. Dex
"$BT/d8" --min-api 21 --lib "$PLATFORM/android.jar" \
  --output "$OUT/dex" \
  $(find "$OUT/classes" -name '*.class')

# 5. Put classes.dex into the APK
(cd "$OUT/dex" && zip -q -u ../base.apk classes.dex)

# 6. Align
"$BT/zipalign" -f -p 4 "$OUT/base.apk" "$OUT/aligned.apk"

# 7. Sign with the debug keystore (create it once if missing)
KEYSTORE="$HOME/.android/debug.keystore"
[ -f "$KEYSTORE" ] || keytool -genkeypair -keystore "$KEYSTORE" \
  -storepass android -keypass android -alias androiddebugkey \
  -keyalg RSA -keysize 2048 -validity 10000 \
  -dname "CN=Android Debug,O=Android,C=US" -noprompt

"$BT/apksigner" sign \
  --ks "$KEYSTORE" --ks-pass pass:android --key-pass pass:android \
  --ks-key-alias androiddebugkey \
  --out "$OUT/signed.apk" "$OUT/aligned.apk"
```

`build/signed.apk` is the installable result; `apksigner` also writes `build/signed.apk.idsig` (v4 signature, default). The skill `android-device-test` installs it.

## Verify

```bash
"$BT/apksigner" verify --print-certs "$OUT/signed.apk"
"$BT/aapt2" dump badging "$OUT/signed.apk" | head -6   # package, versionName, min/target SDK
unzip -l "$OUT/signed.apk" | grep -E "classes.dex|portal.html|resources.arsc"
```

## Rules and gotchas

- Never introduce Gradle files (`build.gradle`, `settings.gradle`, wrapper) or third-party dependencies; the app uses only the Android framework and `org.json`.
- `R.java` is generated by `aapt2 link --java` into `build/gen` - never hand-write or commit it.
- Keep `-A "$SRC/assets"`; without it `assets/portal.html` is missing and the home page is blank.
- Keep `-source 8 -target 8` for javac and `--min-api 21` for d8 to match `minSdkVersion 21`.
- If `zip` is unavailable, run `"$BT/aapt" add "$OUT/base.apk" classes.dex` from inside `build/dex` instead of step 5.
- Update the artifact as `release/ks-portal_<versionName>.apk` (plus the `.idsig`). `versionName`/`versionCode` live in `app/src/main/AndroidManifest.xml:4-5`; bump both together.
- When only resources changed, steps 1-7 still run fine and are cheap (a few seconds); there is no incremental cache worth maintaining.
